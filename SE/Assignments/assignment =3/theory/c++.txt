(2) What is the difference between for, while, and do-while loops in C++?

ans :- Loops are used to repeat a block of code multiple times.

1. for Loop :- Used when the number of iterations is known in advance.

example :- 

for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}

2. while Loop :- Used when the number of iterations is not known and depends on a condition.

example :-

int i = 1;
while (i <= 5) {
    cout << i << " ";
    i++;
} 

3. do-while Loop :- Similar to while, but it executes the code at least once.

example :- 

int i = 1;
do {
    cout << i << " ";
    i++;
} while (i <= 5);


(3)How are break and continue statements used in loops? Provide examples

ans :- 1. break Statement :- The break statement is used to exit the loop immediately, even if the condition is still true.

example :-

#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 5) {
            break;  // loop stops when i = 5
        }
        cout << i << " ";
    }
    return 0;
}

2. continue Statement :- The continue statement is used to skip the current iteration and move to the next iteration.

example :-

#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        if (i == 3) {
            continue;  // skip when i = 3
        }
        cout << i << " ";
    }
    return 0;
}

(2)What is the scope of variables in C++? Differentiate between local and global scope

ans :- In C++, the scope of a variable refers to the region of the program where the variable can be accessed or used.
       Scope determines visibility and lifetime of variables.

1. Local Scope :-
Definition: A variable declared inside a function, block, or loop is called a local variable.
Visibility: Only accessible within the block in which it is declared.
Lifetime: Exists only while the block/function is executing.
Default Value: Not initialized automatically; contains garbage if not assigned.

2. Global Scope :-
Definition: A variable declared outside all functions, usually at the top of the program, is a global variable.
Visibility: Accessible from any function in the program after its declaration.
Lifetime: Exists throughout the program execution.
Default Value: Automatically initialized to 0 (for numeric types).

ans :-

 In C++, recursion is a programming technique where a function calls itself to solve a problem.
 Recursive functions are useful for problems that can be broken into smaller subproblems of the same type,
 like factorial, Fibonacci series, or tree traversals. 

Base Case:-

The condition that stops the recursion.
Without it, recursion would go on forever, causing a stack overflow.

Recursive Case:-

The part where the function calls itself with a smaller/simpler argument.

Always define a base case, otherwise the program may crash due to stack overflow.
Recursion is elegant for problems that have repetitive subproblems.

(2) Explain string handling in C++ with examples.

ans :- In C++, strings are used to store sequences of characters. C++ provides two main ways to handle strings:

C-style strings 
C++ string class from the Standard Template Library 

1. C-Style Strings
A C-style string is an array of characters ending with a null character '\0'.
Basic operations can be done using functions from <cstring>.

Example:-
#include <iostream>
#include <cstring>  // For strlen, strcpy, strcat
using namespace std;

int main() {
    char str1[20] = "Hello";
    char str2[20] = "World";
    cout << "Length of str1: " << strlen(str1) << endl;

    strcpy(str1, str2);
    cout << "After copying, str1: " << str1 << endl;

    strcat(str1, " Everyone");
    cout << "After concatenation: " << str1 << endl;

    if(strcmp(str1, str2) == 0)
        cout << "Strings are equal" << endl;
    else
        cout << "Strings are not equal" << endl;

    return 0;
}

2. C++ string Class
The string class (from <string>) makes string handling easier and safer than C-style strings.
Supports many built-in functions for length, concatenation, comparison, substring, etc.

Example:-
#include <iostream>
#include <string>
using namespace std;

int main() {
    string str1 = "Hello";
    string str2 = "World";

    cout << "Length of str1: " << str1.length() << endl;

    string str3 = str1 + " " + str2;
    cout << "Concatenated string: " << str3 << endl;

    if(str1 == str2)
        cout << "Strings are equal" << endl;
    else
        cout << "Strings are not equal" << endl;

    cout << "Substring of str3: " << str3.substr(6, 5) << endl; // "World"

    size_t pos = str3.find('o');
    cout << "First occurrence of 'o': " << pos << endl;

    return 0;
}

(1) Explain the key concepts of Object-Oriented Programming (OOP).

ans :-Object-Oriented Programming (OOP) is a programming paradigm based on the concept of objects, which contain data (attributes) 
     and functions (methods) that operate on that data. OOP is widely used in C++, Java, Python, and other languages because it helps
     organize complex programs, promotes reusability, and makes maintenance easier.

1. Class
A class is a blueprint or template for creating objects.
It defines attributes and behaviors 

2. Object
An object is an instance of a class.
Objects have their own copy of the class attributes.

3. Encapsulation
Encapsulation means hiding internal details of a class from outside access.
Data members are usually declared private, and accessed through public functions.

4. Inheritance
Inheritance allows a class (derived class) to reuse properties and methods of another class.
Promotes code reusability and hierarchical relationships.

(3)What isinheritance in C++? Explain with an example.

ans :-Inheritance is a fundamental concept of Object-Oriented Programming (OOP) in C++ that allows a class to inherit properties and behaviors from another class.
      This promotes code reusability and establishes a hierarchical relationship between classes.

#include <iostream>
using namespace std;

class Person {
public:
    string name;
    int age;

    void displayPerson() {
        cout << "Name: " << name << ", Age: " << age << endl;
    }
};

class Student : public Person { 
public:
    int studentID;

    void displayStudent() {
        displayPerson(); 
        cout << "Student ID: " << studentID << endl;
    }
};

int main() {
    Student stu;

    stu.name = "Alice";    
    stu.age = 20;          
    stu.studentID = 101;  
    stu.displayStudent();

    return 0;
}
